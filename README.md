# Options Pattern

Nesse repositório temos um exemplo simples do uso de Options Pattern.

## Como Executar Cada Projeto

### 1. Pré-requisitos

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- Editor de código (Visual Studio, VS Code, etc.)

### 2. Clonando o Repositório

```bash
git clone https://github.com/fformis/codando-options-pattern.git
cd codando-options-pattern
```

### 3. Executando os Projetos

```bash
dotnet run --project CodandoOptionsPattern/ CodandoOptionsPattern.csproj
```
